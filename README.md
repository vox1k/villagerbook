# VillagerBook

Клиентский мод для Minecraft (Fabric): записная книжка торговцев.
Запоминает каждого жителя, у которого вы открыли окно торговли, вместе со сделками и координатами.
Потом можно искать, где что продают.

Ставить на сервер ничего не нужно, мод работает только у вас на клиенте и записывает лишь то,
что сервер и так показал вам в окне торговли.

## Использование

1. Откройте окно торговли у жителя (ПКМ), мод запишет его автоматически.
2. В чате:
   - `/vb find mending` - где продают зачарование или предмет (ищет по названию, id и зачарованиям)
   - `/vb find алмазная кирка` - поиск работает и на языке вашей игры
   - `/vb list` - сколько жителей записано
   - `/vb` - справка

Результаты отсортированы от ближайших к вам. Для каждого указаны профессия, уровень, цена, измерение,
координаты и когда вы видели жителя в последний раз.

Данные лежат в `config/villagerbook/<адрес сервера>.json`, для каждого сервера отдельный файл.

## Ограничения

- Мод не узнает, что житель умер или был перемещён. Смотрите на пометку «когда видели».
- Записываются только жители, у которых вы открывали окно торговли.
- Одиночные миры используют общий файл `singleplayer.json`.
- Перед использованием на сервере проверьте правила: на некоторых запрещены любые клиентские моды.

## Требования

- Minecraft 26.3
- Fabric Loader 0.20.1 или новее
- Fabric API
- Java 25

## Сборка

```
./gradlew build
```

Готовый jar появится в `build/libs/` (файл без `-sources` в имени).
